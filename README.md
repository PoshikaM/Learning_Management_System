# 📚 Learning Management System

A **full-stack Learning Management System (LMS)** built with **Next.js**, **MongoDB**, and **Tailwind CSS**.
This project provides a platform where students can learn, track progress, and admins can manage courses with ease.

## ✨ Features

- 🔐 Authentication with NextAuth.js

- 🧑‍🎓 Student Dashboard – track enrolled courses and progress

- 🧑‍💼 Admin Dashboard – create and manage courses

- 📘 Course Management – creation, enrollment & progress tracking

- 📱 Responsive & Modular UI powered by Tailwind CSS

## 🛠️ Tech Stack

- Framework: ⚡ Next.js (App Router)

- Database: 🍃 MongoDB (via Mongoose)

- Authentication: 🔑 NextAuth.js

- Styling: 🎨 Tailwind CSS

- Language: 📝 JavaScript

## 🚀 Getting Started

Follow these steps to set up the project locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/lms-project.git

# Move into the project folder
cd lms-project

# Install dependencies
npm install

# Start the development server
npm run dev
```

Your app will be running on: 👉 http://localhost:3000
